# Configuration

![Settings](pictures/Settings.png)


## Chrome Path

Sets the custom path for Chrome or Chromium-based browser to export PDF, PPTX, and image. If it\'s empty, Marp will find out the installed Google Chrome / Chromium / Microsoft Edge.

## Theme Path

Local paths to additional [theme CSS](https://marpit.marp.app/theme-css) for Marp core and Marpit framework. The rule for paths is following Markdown: Styles.

## Export Path

Specifies the user-defined path for exporting PDF, PPTX, and images. If left empty, Marp will export them in the same folder as the note. It's important to note that the export path has no impact on HTML exports.

## Enable HTML

Enable all HTML elements in Marp Markdown. Please Attention when you enable!!!

## Math Typesettings

Controls math syntax and the default library for rendering math in Marp Core. A using library can override by math global directive in Markdown.

## HTML Export

**This is an EXPERIMENTAL feature**

Controls HTML library for eporting HTML File in Marp Cli. bespoke.js is experimental

## Sync Preview

**This is an EXPERIMENTAL feature**

## Slide Ratio

Default aspect ratio for slide decks: `16:9` (1280×720, default) or `4:3` (960×720).
The ratio applies to the preview and to every export — PDF page size, PPTX slide size
and PNG snapshots. It is staged as Marp's native `size` directive, and custom theme
CSS without `@size` metadata is patched automatically so the directive is honoured.

Override per deck in the note's frontmatter:

```yaml
---
marp-slides:
  ratio: 4:3
---
```

A native `size: 4:3` Marp directive works as well and always wins when present.

## Code Highlight Theme

Color palette for code blocks: `auto` (default, keep the slide theme's own styling),
`github`, `github-dark`, `one-dark`, `monokai` or `dracula`. Applies to the preview
and all exports (the export engine appends the palette CSS after the theme CSS).

Override per deck with `marp-slides: code-theme:` in the frontmatter.

## Mermaid Theme

Theme used when rendering mermaid diagrams: `default` (default), `neutral`, `dark`,
`forest` or `base`. Local (offline) rendering passes it to the bundled mermaid
runtime; Kroki rendering injects it into each diagram as an `%%{init}%%` directive.

Override per deck with `marp-slides: mermaid-theme:` in the frontmatter.

## Mermaid Font Family

Font mermaid uses to **both measure and draw** diagram labels in local render
mode. Use a font that is actually installed on the machine (not a web font):
diagrams are pre-rendered to SVG while the plugin runs, but rasterised later by
the export browser — if the two disagree on the label font, CJK labels come out
wider than their boxes and get clipped (`Web` → `Wel`). The default is a
CJK-capable system-sans stack (`"Microsoft YaHei", "PingFang SC", …`). Leave it
empty to fall back to mermaid's own default (`trebuchet ms`), which is fine for
Latin-only diagrams. Labels are drawn as plain SVG text, so even a small
mismatch overflows the box visibly instead of being cut off.
